# 生活费规划

一个只在手机上使用的本地生活费 PWA。目标不是记流水账，而是在钱很少、下一笔到账日期还不确定时，先算出“今天最多还能花多少”。

如果预计到账日变化，在首页点“调整到账日”。贷款实际到账后点“贷款到了”，输入实际金额并开始一年周期。

## 怎么用

1. 每次花钱点“记一笔”，选对分类和付款账户。
2. 洗衣点“洗衣 ¥0.60”，吹风点“吹风 ¥1.00”，这两项自动选择支付宝。
3. 需要从微信转钱到支付宝时，点“账户互转”。互转不会算消费，也不会改变总生活费。
4. 大学生活费到账或父母转账时，在“明细 → 到账”里补记，并选对账户。
5. 每花一笔，首页的今日可花金额都会立即重算。

## 数据与隐私

- 数据保存在当前手机浏览器的 IndexedDB 中，不上传服务器。
- 没有账号、没有广告、不读取银行卡、不请求支付权限。
- 清除浏览器站点数据会删除账本，请定期在“明细”页导出 JSON 备份。
- 换手机时先导出，再在新手机导入。

## 安装到桌面

- iPhone：Safari 打开 → 分享 → 添加到主屏幕。
- 安卓：Chrome 打开 → 菜单 → 安装应用 / 添加到主屏幕。
- 安装后可以离线打开。

## 有意没做

- 不做跨设备同步和登录。
- 不做后台系统通知，提醒只在打开应用时出现。
- 不接入银行账单。
- 不自动猜测洗衣或吹风频率；按实际使用点快捷记账。
